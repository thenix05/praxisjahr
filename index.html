Was man anschauen kann

Aufgabe. Ich musste die Prüfung Waffentragen vorbereiten und wollte die Fragen üben statt sie nur zu lesen.

Entscheidung. Eine einzelne HTML-Datei ohne Framework. Antworten über die Zifferntasten, Fortschritt lokal im Browser gespeichert, damit man zwischendurch weitermachen kann.

Grenze. Die richtigen Antworten stammen aus dem öffentlichen Katalog des fedpol, die falschen Vorschläge habe ich selbst ergänzt.

Ausprobieren

Aufgabe. Eine kleine Web-API mit Datenbank, die sich auf jedem Rechner gleich starten lässt.

Entscheidung. Minimal API statt Controller, Datenbank und Anwendung zusammen in einer docker-compose-Datei, damit ein einziger Befehl genügt.

Grenze. Keine Authentifizierung, keine Tests. Das Projekt zeigt den Aufbau, nicht den Betrieb.

Code ansehen

Aufgabe. Verstehen, wie zuverlässig Texterkennung bei unterschiedlichen Vorlagen wirklich ist.

Entscheidung. Tesseract über das NuGet-Paket, Ausgabe von Text und mittlerer Zuverlässigkeit. Bildpfad und Sprache kommen als Argumente, damit es nicht nur auf meinem Rechner läuft.

Grenze. Bei Kontrollschildern ist die Erkennung deutlich schlechter als bei einem Flyer. Eine Vorverarbeitung der Bilder fehlt noch.

Code ansehen

Aufgabe. Zu einer vorgegebenen Anwendung eigene Tests schreiben, inklusive Stubs und Spies.

Entscheidung. Aufbau nach dem AAA-Muster, jede Testklasse prüft eine Verantwortlichkeit, Test Doubles nur dort, wo eine echte Abhängigkeit den Test langsam oder unzuverlässig macht.

Grenze. Ein Übungsprojekt aus dem Modul 450, keine eigene Anwendung.
